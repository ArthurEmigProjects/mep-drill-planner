# Examples

- Drop an anonymised MEP `.ifc` here (never real client models).
- `out/` is gitignored; generated JSON points land there.
- Zenodo duplex (Teclaw, 2024, CC BY 4.0): piping and ventilation are `zenodo-duplex-piping.ifc` and `zenodo-duplex-ventilation.ifc`. Heating and architecture are `HeatingAndCooling.ifc` and `Architecture.ifc`.
- The mountable-element inventory is written to `data/inventory/`, not to `out/`.
