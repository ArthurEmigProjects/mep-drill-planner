Select an IFC file

Pick a sample model or open an .ifc from this computer. The file stays local. View in 3D draws the selected model, and any file ticked For clashes, with That Open Engine. Open in window puts that same view in its own browser window. Extraction uses the top of each MEP element’s bounding box. Placement spaces hangers along each straight run, shows when a clash moves one, and writes a separate mounting IFC. The object list selects a hanger so it can be moved, deleted, or restored with Undo and Redo. View in 3D loads that IFC beside the model. The view tools can hide it, and can filter hangers by non-problematic, moved, or clashing, and by sanitary, heating/cooling, or ventilation. Tick For clashes on other IFCs when they hold beams or the rest of the services a rod can hit. Clash drawings PDF writes a floor plan for each level, a long section, a cross section, a section at each unresolved clash, and 3D views.
