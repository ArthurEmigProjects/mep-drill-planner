# Mounting Points

The mounting points can be initialized based on maximally allowed mounting spacing.

The aim is to place the mounting points regularly distributed across the whole length of installation element. The maximum spacing should be around 70% of maximally allowed spacing.

Then clash check should be applied and the distances should be corrected in the span of 90-95% of maximally allowed spacing.

The task is to write code that 
a) detects the runs of pipes, ventilation ducts, etc.;
b) places the mountig points
c) checks vertically if there are clashes
d) if there are clashes, adjusts the mounting points as described above
